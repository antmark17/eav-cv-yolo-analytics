# Profili camera

Conservare qui, separati dal profilo generico video, i YAML calibrati per le singole inquadrature reali.

Esempi di naming:

- `napoli_garibaldi_cam_01.yaml`
- `pompei_cam_03.yaml`

Riutilizzare un profilo solo quando camera, crop, orientamento e geometria della scena sono compatibili.
